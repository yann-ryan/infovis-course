ggplot Exercises

These exercises are designed to test your knowledge of the course material up until this point. They use two datasets we have used on the course, the Titanic dataset and the pair of Nobel Prize tables. It can take a minute or two to load the first time.

The checking software looks for an exact match to the code you have written, which is very unlikely. Instead, try to write your own solution, and consider it correct if your resulting plot roughly matches the description. Use the ‘Show Solution’ button to compare your code to the expected version, or to look at the answer if you can’t figure it out.

Exercise 1

Join the laureates and prize_df datasets by prize_id, and create a bar plot showing the number of laureates in each Nobel Prize category. Use geom_bar(). The plot should have the title “Nobel Prize Categories” and labels “Prize Category” for the x-axis and “Number of Laureates” for the y-axis. Use the theme_minimal() theme.

Use geom_col(), and customize the plot with the required title, labels, and theme.

laureates |> left_join(prize_df, by = "prize_id") |> group_by(category) |> summarise(n = n()) |> ggplot(aes(x = category, y = n)) + geom_col() + labs( title = "Nobel Prize Categories", x = "Prize Category", y = "Number of Laureates" ) + theme_minimal() 
laureates |> 
  left_join(prize_df, by = "prize_id") |> 
  group_by(category) |>
  summarise(n = n()) |> 
  ggplot(aes(x = category, y = n)) +
  geom_col() +
  labs(
    title = "Nobel Prize Categories",
    x = "Prize Category",
    y = "Number of Laureates"
  ) +
  theme_minimal()
